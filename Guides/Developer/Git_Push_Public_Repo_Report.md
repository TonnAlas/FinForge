# Git Push to Public Repo - Not Pushed Report

## Scope

This report explains what does not get pushed when you push the current branch to the public remote. It uses the current repository state as of 2026-05-02 and reflects the decision to keep all data under data/ local only.

Assumptions:
- Branch: Main_Public_Test
- Remote tracking branch: origin/Main_Public_Test
- "Public repo" refers to the origin remote.

## How to read this report

- The rules section explains what Git can and cannot push.
- The ignore section lists patterns Git skips on every branch, including main.
- The commit intent section states what should and should not be exported.
- Only committed changes are pushed; untracked, modified, or staged changes stay local.
- All data under data/ is intended to stay local; only data/.gitkeep should be tracked.

## What does not get pushed (general rules)

1. Uncommitted changes (modified or deleted tracked files) are not pushed.
2. Untracked files and folders are not pushed until added and committed.
3. Ignored files (from .gitignore, .git/info/exclude, or global gitignore) are not pushed.
4. Local-only refs (stashes, local branches, tags not explicitly pushed) are not pushed.
5. Local config and hooks (e.g., .git/config, .git/hooks/*) are never pushed.

## Simple meanings (like I am 5)

These are the words used in this file, explained very simply.

- Tracked: Git knows about the file and is watching it.
- Untracked: Git does not know about the file yet.
- Staged: The file is in a waiting area to be committed.
- Committed: A saved snapshot in Git history.
- Modified: A tracked file changed, but not saved into a commit yet.
- Deleted: A tracked file removed, but not saved into a commit yet.
- Ignored: Git is told to not pay attention to the file.
- Pushed: Commits are sent from your computer to the remote repo.

Think of it like this:
- Tracked is like a toy in your playroom that you always watch.
- Staged is like putting toys in a box to save them.
- Committed is like sealing the box and labeling it.
- Pushed is like mailing the box to a friend.

## What is ignored when committing to main

Git ignores the same files no matter which branch you commit on, including main. Ignored files are not staged by `git add .` and do not enter commits unless you force-add them.

From this repo's ignore rules, these are ignored by default:

| Category | Patterns or folders | Notes |
| --- | --- | --- |
| Data | data/** (except data/.gitkeep) | All API-fetched data stays local. |
| Python virtual envs | .venv/, venv/, env/, ENV/ | Local environment only. |
| Python cache | __pycache__/, *.py[cod], *$py.class | Generated bytecode. |
| Python tooling caches | .pytest_cache/, .mypy_cache/, .ruff_cache/, .coverage, htmlcov/, .tox/, .nox/, .hypothesis/, .ipynb_checkpoints/, __pypackages__/ | Test and lint artifacts. |
| Build output | dist/, build/, *.egg-info/, *.egg | Build products. |
| IDE/editor files | .vscode/, .idea/, *.swp, *.swo, *~ | Local editor state. |
| OS files | desktop.ini, .DS_Store, Thumbs.db, ehthumbs.db | OS metadata files. |
| Excel temp files | ~$*.xlsx, ~$*.xlsm, ~$*.xls | Office temp files. |
| Logs | *.log | Runtime logs. |
| Local config | .env, .env.local, config.local.json | Local secrets or config. |
| Temporary | Temporary/* (except Temporary/.gitkeep) | Temporary outputs only. |
| Backups | *.bak, *.backup, Backups/ | Local backups. |

## Commit intent - what should be exported

This section states what should and should not be exported to the public repo on Main_Public_Test.

| Category | Export to Main_Public_Test? | Details |
| --- | --- | --- |
| Application code, docs, configs | Yes | Everything needed to build, run, and maintain the project. |
| Data from APIs (ticker data) | No | All data under data/** stays local. Only data/.gitkeep is tracked. |
| Temporary outputs | No | Temporary/** (except Temporary/.gitkeep). |
| Cache and tooling artifacts | No | __pycache__/, *.pyc, .pytest_cache/, .mypy_cache/, .ruff_cache/, .coverage, htmlcov/, .tox/, .nox/, .hypothesis/, .ipynb_checkpoints/, __pypackages__/. |
| Local environment files | No | .venv/, venv/, env/, ENV/, .env, .env.local, config.local.json. |
| Editor and OS metadata | No | .vscode/, .idea/, *.swp, *.swo, *~, desktop.ini, .DS_Store, Thumbs.db, ehthumbs.db. |
| Logs and backups | No | *.log, *.bak, *.backup, Backups/. |

Notes:
- .git/info/exclude contains only comments, no active exclude rules.
- Some __pycache__ and *.pyc files are tracked despite .gitignore; ignore rules do not apply to already tracked files.
- All data files are now ignored for future changes; only data/.gitkeep should remain tracked after the staged deletions are committed.

## How to include or exclude items

To include untracked or modified items in the push, add and commit them:

```bash
git add <path>
git commit -m "Describe the change"
git push
```

To stop tracking something that is already tracked but should be ignored:

```bash
git rm --cached <path>
```

Then add an ignore rule to .gitignore and commit the change.
