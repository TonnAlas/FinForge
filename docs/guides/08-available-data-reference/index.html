Using This Data

In Ratio Formulas

Use these prefixes to reference data:

Prefix Data Source
IS: Income Statement
BS: Balance Sheet
CF: Cash Flow

Example formulas:

  • IS: Net Income / BS: Total Assets (ROA)
  • BS: Total Debt / BS: Stockholders Equity (Debt to Equity)
  • CF: Free Cash Flow / IS: Net Income (FCF Conversion)
