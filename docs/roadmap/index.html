Roadmap

FinForge keeps improving. This page lists the features that are currently in the work or on the table for future releases. These are ideas and plans, not shipped features, so details can change as priorities are reviewed.

Upcoming features

Broker Connection

Connect your own broker account to view holdings, balances, and positions, and sync a live portfolio. The first version is planned to be read-only, with order placement later.

Portfolio Theory Modeling

Modern portfolio theory analysis: expected return, volatility, correlation matrices, an efficient frontier, and optimal portfolio weights.

Discounted Cash Flow Model

A multi-stage DCF valuation tool with terminal value, WACC estimation, and sensitivity tables.

Market Map

A browsable map of the full public stock universe, filterable by metric, sector, industry, market cap, and more.

Custom One-Pager Overview

A one-page stock summary template you can fill with any parameters you choose, then export and print.

Community Presets

Export, import, and share ranking presets and ratio definitions as portable, validated JSON files.

Advanced Graph Settings

More granular chart controls, including per-series styling, multiple y-axes, annotations, drawing tools, and saved chart presets.

Flexible UI and Settings

Layout persistence, per-user themes, configurable default tabs, and a searchable settings page.

Custom Formulas

Define your own Excel-style formulas from existing metrics and use them in ratios, ranking, screening, and charts.
